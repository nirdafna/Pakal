# פק"ל — Pakal

Marketing and traveler-content site for **פק"ל** ("נהנים בכל דרך"), a Hebrew family card
game for travelers. Every card in the deck carries an Israeli landmark or trek and a QR code
that leads here.

Hebrew-first, RTL, static-first. Built with Astro, content managed in Sanity, hosted on
Vercel.
